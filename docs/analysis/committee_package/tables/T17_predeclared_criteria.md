**Notes.**

- One row per gate, reading, criterion or scoring convention that was fixed before the data it judges were read.
- ordering_evidence says how the 'before' is established: 'git' when the commit that wrote the criterion precedes the commit that ran or read the data; 'plan_text' when the criterion was first committed together with its result, so only the plan's own statement dates it.
- status: pass / not_met / partial / descriptive (no pass or fail by design) / convention (fixed rule, not a test) / deviation (a change made after data were read).
- Commit dates are local time (-0700). The ledger docs/DECISIONS.md is authoritative where a patch document disagrees.
