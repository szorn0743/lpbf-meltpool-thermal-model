# Results

The frozen results of the thesis, as the development run recorded them. Nothing here is regenerated by the tests;
`results/committee_package`, `results/thesis_figures` and `results/figure_sources/source` are rebuilt by
`python -m lpbf.reproduce analysis` from the recorded run and must come out byte-identical.

| Folder | What it is | Produced by |
|---|---|---|
| `calibration/` | The calibration of the thesis. `PREDECLARED_PLAN.md` is the protocol fixed before the run (its SHA-256 is recorded in every stage manifest as `plan_sha256`); `RESULTS.md` the results and failure modes; `smoke/`, `calibrate/`, `confirm/`, `evaluate/`, `synthetic/` the stage manifests (every input and output file with its SHA-256, the per-candidate scores, the readings); `selection_freeze.json` the selected parameters, frozen before any held-out coupon was read; `calibration_reading.json` the reading C; `pre_fix/` the first confirmation stage, superseded by a documented code fix before the freeze (see its README). | `lpbf.calibration` (development commits `bebec6d`–`2fdc58c`, 2026-10-15/16) and `lpbf.observation_operators` |
| `camera_diagnostic/` | The diagnostic of the H mismatch that preceded the calibration: camera-side characterization (step 0: direction test, member summary, threshold family, trends), the synthetic-camera scan (step 3: level-free isotherm check), the design-box scan on the corner coupons (step 4: candidates, verdict). `PREDECLARED_PLAN.md` and `FINDINGS.md` are its protocol and findings. Only the files the analysis reads are kept. | the camera diagnostic code of 2026-10-15 (`lpbf.camera_observations`, `lpbf.synthetic_camera` and their removed runners) |
| `synchronization_audit/` | The audit of the camera–process synchronization anchors on all 24 coupons (two campaigns, two anchor conventions; the reason for the scored-frame rule). | the association census of 2026-10-14 (removed runner) |
| `smoke_reference/` | The frame records and per-coupon objective of the gate unit (`anchor_center` × `20260730:part_1`) under the production semantics, which every smoke stage must reproduce bit for bit. | the Stage-A verification run of 2026-10-14 |
| `committee_package/` | The statistical outputs prepared for the thesis committee (tables T1–T19, figures F1–F15, datasets D1–D10, registers of predeclared criteria and data use). Items not predeclared are flagged exploratory in `METHODS_MANIFEST.json`. | `committee_package/scripts/run_all.py` |
| `thesis_figures/` | The tables T1–T10 and figures F1–F13 of thesis Chapters 3–4, and `thesis_tables_and_figures.docx`. | `thesis_figures/scripts/build.py` |
| `figure_sources/` | The image sources (representative frames, outlines, per-condition sizes) that the thesis figures read, with the scripts that extract them from the coupon files and the recorded fields. | `figure_sources/scripts/build_sources.py` |

The unit files and temperature fields of the recorded run are in the data bundle (`runs/recorded_calibration/`,
see `data/README.md`); the stage manifests here hold their SHA-256, so a rerun can be checked file by file.
